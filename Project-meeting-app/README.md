🚀 Meeting.App - Real-time Video Conferencing Platform
Meeting.App là một nền tảng họp trực tuyến hiện đại, hỗ trợ giao tiếp video/âm thanh thời gian thực, chat và chia sẻ dữ liệu. Dự án được xây dựng với kiến trúc tách biệt (Decoupled Architecture) giữa Frontend và Backend để đảm bảo khả năng mở rộng (scale) và tối ưu hóa hiệu suất cho các tính năng WebRTC/Socket.io.

\*\*\*\* Cách chạy dự án
Ở thư mục FE chạy npm run dev, tương tự với BE
